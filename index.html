About me

I build web applications and business software around how companies actually work.

My work centers on PHP, Laravel and MySQL. I enjoy turning a business process (orders, inventory, records, approvals, reports) into a structured, database-driven application that people can use every day. ERP-style systems are my main focus, because they reward careful data design and clear workflows.

I approach each project practically: understand the problem first, model the data properly, then build maintainable code with responsive, usable interfaces. Alongside web development I work with Python and Streamlit on machine-learning demonstrations.

  • Database-driven application development
  • Business workflows and ERP functionality
  • Maintainable code
